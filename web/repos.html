저장소 관리 (자동 업데이트)

EDOPro 와 같은 방식으로 카드 DB·스크립트·금제를 GitHub 에서 받아 게임에 적용합니다. 서버가 주기적으로 갱신하고, 게임 화면을 새로고침하면 최신 데이터가 적용됩니다.

적용 상태

불러오는 중…
게임에 적용하려면 게임 화면을 새로고침하세요.

저장소

이름최신 커밋파일원격

동작 방식

서버기동 시 + 6시간마다 git fetch + reset 로 저장소를 갱신합니다.
게임화면을 열 때 /api/repos/bundle 을 받아 expansions/·script/·lflists/ 에 넣고 시작합니다. (변경 없으면 304 → 즉시)
지원 파일*.cdb → 카드 DB · *.lua → 스크립트 · *.conf → 금제
