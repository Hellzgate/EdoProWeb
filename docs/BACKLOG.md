## P0 — 실사용 검증 (다음 세션 최우선)

| # | 항목 | 왜 | 방법 / 완료 기준 |
|---|---|---|---|
| 1 | **실제 듀얼 1판** (봇 대전) | 화면·덱 편집만 확인했고 전투/체인/효과는 미검증 | `LAN + AI 대전` → 방 생성 → 봇 `b:raisemoon` 또는 `bot` → 1판 완주. 확인: 소환/공격/효과/체인/승패, 오류 콘솔 0 |
| 2 | **서버 대전 방 목록·입장** | 프록시(`{"rooms":[]}`)만 확인 | 멀티롤에서 방 생성 → 웹에서 목록 표시·입장·듀얼 시작까지 |
| 3 | **덱 이름/방 이름 등 콤보 내부 입력** | IME 브리지는 **편집박스** 포커스에만 반응. 덱 이름은 **콤보(내부 편집박스)** 라 모바일에서 이름 변경이 안 될 수 있음 | 폰에서 덱 이름 콤보를 눌러 타이핑 → 변경·저장 확인. 안 되면 콤보 내부 edit box 포커스도 브리지에 연결 |
| 4 | **모바일 한글 입력** | ASCII(`PlayerHello`)만 검증 | 폰 키보드로 `가나다` 입력 → 게임에 그대로 들어가는지(조합 문자 전달) |
| 5 | **파일 올리기/내려받기** | 📁 → `/files.html` 연결만 확인 | 폰에서 덱 `.ydk` 업로드 → 덱 편집 목록에 표시, 리플레이 업로드/다운로드 |
