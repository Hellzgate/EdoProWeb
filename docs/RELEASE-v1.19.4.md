## 수정 — "너무 느림" + "금제 선택 불가"
**원인은 하나**: Game::Draw() 가 매 프레임 ParseGithubRepositories(GetReadyRepos()) 를 호출하는데,
웹 스텁이 **항상 "준비된 리포 5개"를 반환**했다.

매 프레임 발생한 일:
1. lflist 파일(~700KB) 재파싱
2. _lfList 중복 누적 → 실측 **13,209개**
3. 금제 콤보를 13,209개 항목으로 재생성

→ FPS 2~9, 콤보는 중복 목록 끝에서 열려 선택이 리셋됨(선택 불가처럼 보임).
