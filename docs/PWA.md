## PWA (홈 화면에 추가) — 폰에서 주소창 없이 전체화면

EDOPro Web 은 `manifest.json` 에 `display: fullscreen`, `orientation: landscape` 를 선언해 두었다.

### Android (Chrome / 네이버 웨일)
1. `https://sw20103.synology.me:8451/` 접속
2. 브라우저 메뉴 → **홈 화면에 추가** (웨일: `⋮` → `홈 화면에 추가`)
3. 홈의 아이콘으로 실행 → **주소창 없는 전체화면(가로)** 으로 시작
4. 이미 열려 있으면 우상단 **⛶** 버튼으로도 전체화면 전환 가능(웨일 확인)

### iOS (Safari)
- 공유 → **홈 화면에 추가** → 실행 (Safari 는 전체화면 API 제약이 있어 하단 바가 남을 수 있음)

### 확인 포인트
- 실행 시 화면이 **가로**로 고정되고 주소창이 사라지는지
- 로딩 오버레이 1탭 → 게임 진입
- 폰을 돌려도 캔버스가 깨지지 않는지(세로는 레터박스 + 안내 문구)

### 문제 시
- 전체화면이 안 되면: 브라우저가 PWA/전체화면을 막는 경우 → Chrome 최신 버전 사용, 또는 `⛶` 버튼 사용
- 흰 화면: `/last.html` 로그 확인 → 새로고침(ETag 304 로 재다운로드 없음)
